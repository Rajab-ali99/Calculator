# Simple Calculator

A lightweight and beginner-friendly calculator application that performs basic arithmetic operations. This project is ideal for learning fundamental programming concepts and user input handling.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Simple and clean interface
- Fast and easy to use

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Project Structure

```
simple-calculator/
│
├── index.html      # Main HTML file
├── style.css       # Styling
├── script.js       # Calculator logic
└── README.md       # Project documentation
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/simple-calculator.git
```

2. Navigate to the project folder:

```bash
cd simple-calculator
```

3. Open `index.html` in your preferred web browser.

No installation or dependencies are required.

## Usage

1. Enter the first number.
2. Select an arithmetic operation.
3. Enter the second number.
4. Click the **Calculate** button.
5. View the result instantly.

## Example

| Input | Operation | Input | Result |
|-------|-----------|-------|--------|
| 10 | + | 5 | 15 |
| 20 | - | 8 | 12 |
| 6 | × | 7 | 42 |
| 15 | ÷ | 3 | 5 |
